# 淘宝双11 ADB 任务助手

Windows 本地工具，Python 3.14 + Tkinter，无第三方 Python 依赖。支持淘金币赛车与寻宝中国直播浏览两种活动模式。手机通过 USB 连接电脑，手动打开对应活动任务页后启动。
## 用前须知
1. 如果你不会用，那么就复制此仓库的链接然后发给AI，让AI给你部署。
2. 此ADB助手支持淘金币双十一赛车的浏览、跳转及已适配的每日单选答题，以及“寻宝中国”的直播浏览任务。邀请好友、游戏、积分兑换不执行；新页面结构仍可能需要适配。
3. 只在我本人的小米手机使用过。
4. 遇到任何问题，发issue/pr。
## 首次安装

1. 在 Windows 安装 Python 3.14（包含 Tkinter），安装时启用添加到 PATH。
2. 克隆仓库或下载源码，进入项目目录。
3. 从 [Android 官方 Platform Tools](https://developer.android.com/tools/releases/platform-tools) 下载 Windows 版，解压到 `tools/platform-tools/`，使 `adb.exe` 位于该目录；也可以启动后手动选择 ADB 路径。仓库不分发 ADB 二进制。
4. 手机开启 USB 调试并确认电脑授权，打开对应活动任务列表，然后双击 `start.cmd`。

```powershell
git clone https://github.com/K1llery/taojinbi-adb.git
cd taojinbi-adb
```

## 使用

1. 双击 `start.cmd`。如果已经开着开发过程中的测试窗口，先关闭旧窗口再打开。
   在窗口右上选择“淘金币赛车”或“寻宝中国 · 直播”；活动选择会保存在本机。切换活动后重新扫描，不会沿用另一活动的勾选。
2. 点击“检查连接”，确认设备，然后点击“扫描任务”。
3. 默认勾选“自动处理当前活动的全部可执行任务”，设置本次上限，点击“开始执行”。上限 `0` 表示持续发现并处理入口，直到耗尽或遇到异常。取消自动模式后，可以按列表勾选指定入口。
4. 可以暂停、继续或停止。停止后不再发送新操作；手机已经接收的手势可能完成。
5. “打开本地记录”可查看这次会话的日志、XML 和截图。
6. “执行结束／故障提醒”只在整次执行完毕或遇到故障时提醒，单个任务成功只更新计数。故障提示包含原因，可恢复的单项故障也会提醒；手动停止、检查连接及扫描不发执行结束提醒。可以分别关闭“响铃”和“置顶提示”，两个开关都会记住。

保持手机亮屏、淘宝处于前台，并避免同时手动操作。无需再给每个任务演示流程。

小米设备需启用“USB 调试（安全设置）”，首次开启后重启手机。

## 淘金币赛车支持范围

- **沉浸浏览**：等待页面任务组件结束，包含“好物沉浸看”等会轮换的名称。
- **商品列表浏览**：进入一张完整可见的商品卡片，浏览后返回，确认顶栏已得奖励；包含“好物随心逛”、`看看#…` 等入口。
- **签到与拍立淘浏览**：识别页面浏览组件并等待。拍立淘仅处理已有结果页，不拍照或上传图片；签到不操作提现、红包使用等按钮。
- **两种搜索浏览**：普通淘宝搜索页输入商品词后等待结果页任务浮标；“搜索有福利”页输入后进入结果中的商品阅读。默认商品词为“鼠标”，命令行可用 `--query` 修改。
- **淘金币省钱等级考试**：支持实际显示2—4个连续选项的单选题，已实测三选一与四选一。按用户指定的选项长短规则：三／四选一比较最短两项与最长两项的长度差，短端差距更大时选最短，否则选最长；二选一选最长，同长度优先最先出现的最长项，忽略空白。不接入AI。选中及结果图标不计入答案文字；重复、隐藏、离屏或缺少中间选项仍停止。每次访问绑定题目与选项，只提交一次；题目变化即停止。实际对错与奖励单独记录，答错获得部分奖励也按真实发放量核验，不将最高奖励当作实际到账。
- **攻略页**：已有条件识别与阅读处理，但今天该入口已完成，本轮没有取得未完成攻略页的真机验证。
- **跳转其他 APP**：文案只作提示，是否跳转由设备决定——点击“去完成”后读前台包名，出现外部应用即按跳转处理，仍在淘宝内则按站内页处理。`去惊喜好物逛一逛` 留在站内、`看淘宝视频领红包` 反而跳到站外，所以不能靠标题判断。外部应用内不点击任何按钮，停留 2 秒即返回。
- **跳转返回与主页恢复**：使用完整启动器 Intent 恢复淘宝任务栈；如果仍停在发起跳转的站内页，再在淘宝内返回，最多3次。识别到淘金币活动主页就点击“赚能量”重开列表；识别到淘宝首页就用本机实测的固定淘金币活动入口进入，再打开列表。外部应用、任务列表及两个主页上均不发送返回键。恢复入口变化或超过次数上限时停止并保存记录。
- **只在外部应用位于前台时才拉起淘宝**。已经在淘宝内时绝不调用 `am start`：那会新建一个 `Welcome` 活动并落回店铺首页，任务列表随之丢失。
- **前台被外部应用抢回时自动恢复**：任务间隔里如果发现前台不是淘宝（真机上百度会自己回到前台），先静默拉起淘宝任务栈再继续，不会因此停机。
- **系统启动确认框**：已适配小米“淘宝想要打开某应用，是否允许”的“本次允许”。仅在来源为淘宝、目标与当前任务的应用及版本匹配时点击一次，不修改“始终允许”。系统窗口与桌面启动器不计为目标应用；其他系统权限、选择器及登录验证仍需人工处理。切换瞬间读不到活动窗口时，最多重读3次。
- **站内纯跳转**：没有浏览时长的“点击去逛”任务，确认站内页面后停留2秒再返回；如果随后跳到其他应用，接续站外跳转流程，不再套用15秒浏览默认值。明确标注浏览时长的任务仍按原浏览要求处理。
- **无奖励组件的站内活动页**：浏览任务可能落到车库页、闪购页等站内活动页，页面里没有“浏览N秒”浮层。连续 3 帧都识别为站内未知页面就按任务标注的时长停留，再返回核验。不要求帧内容一致——闪购页有倒计时，文字每帧都在变。
- **安装状态检查**：百度极速版、点淘、一淘等按设备真实安装包判断；已移除百度极速版旧的固定排除规则。普通版与极速版分别匹配各自包名，安装极速版不要求同时安装普通版。确实未安装的APP跳过；若入口实际要求下载安装指定版本，仍跳过，不点击下载或安装。
- 自动模式按浏览时长和页面任务组件发现任务，每次操作重新定位。完成后重新发现列表，支持名称与位置轮换。新的任务页面仍需单独适配，无法保证未来所有活动页直接可用。
- 同一帧出现同名但次数或按钮位置不同的行时，将该名称标记为歧义并暂不执行，继续处理其他可识别入口。不会靠次数较大或其他行的相同次数推断身份。
- 手动勾选按明确名称执行；任务换名后需要重新选择。需要持续跟随换名、换位时，使用默认的自动模式。列表位置变化不会把手动勾选转移给其他任务。
- **任务分类以详情行为准**：标题是营销文案。`领闪购红包下单直接省` 标题含“下单”，详情却是 `点击去逛`，属于跳转任务。只有详情命中交易/社交/答题类要求时才跳过。
- 小游戏、邀请、积分兑换、下载安装、交易、关注、收藏、加购、授权及其他未适配答题均跳过；标题中含“关注”等词但详情明确只要求浏览时，仍按浏览任务处理。累计任务奖励的“立即领取”由用户手动处理。
- 验证、风险或网络提示、断连及无法恢复任务列表等会话级问题会停止输入。未知站内页面按前述计时流程处理；预期跳转后的外部应用按返回流程处理。不会自动解决验证码、系统权限弹窗或登录。
- 单个任务失败可以恢复列表后继续。同一名称 2 次未确认后在本次会话跳过；连续 3 次任务未确认会停止整个会话，任务换名也计入该上限。失败会记录原因。
- 未封顶时，跳转与无奖励组件计时任务要求总进度恰好增加1；有奖励组件的浏览任务还要求同组次数唯一变化，或本次页面由浏览中转为完成。单项次数存在歧义时明确记录“单项次数未归因”。奖励数字精确匹配，商品标题中的完成文字不会作为任务组件证据。
- **每日能量上限 50/50 之后**，要求同组单项次数唯一增加1，或本次浏览奖励组件明确由进行中转为完成。纯跳转还可依据本次目标访问及赛车能量恰好增加该行正奖励确认：任务前后各关闭并重开弹层，读取刷新后的能量；期间暂停会使这份能量证据失效。名称消失、换名、离屏和歧义均不能独立证明完成；缺少证据会记录未确认，不能凭停留时长报成功。
- 通用奖励浮层先识别浏览倒计时与奖励，再绑定本次组件位置；完成文案替换倒计时后仍可识别。孤立的完成文字不会被接受。

等待依据页面加载和任务要求；任务间采用5—10秒阅读间隔，避免连续快速点击。此工具无法保证不被平台识别。无障碍权限检测处理未实现。

## 命令行和离线测试

```powershell
python -m taojinbi --scan
python -m taojinbi --all-browse --limit 0
python -m taojinbi --all-browse --query 鼠标 --limit 1
python -m taojinbi --task 好物沉浸看 --limit 1
python -m taojinbi --task 好物沉浸看 --limit 0
python -m unittest discover -v
```

多台设备连接时使用 `--serial` 指定设备。命令行默认上限1次；窗口默认0。相同设备在本工具中只允许一个扫描或运行会话。

## 页面读取器与本地数据

`tools/ui-dump.jar` 是由本项目 Java 源码构建的约5KB页面读取器，经 ADB 临时放入 `/data/local/tmp/` 执行。它复用 Android 自带 UiAutomationShellWrapper 连接生命周期，直接读取控件树，避开系统 `uiautomator dump` 在动画页等待静止失败的问题。搜索文字通过 UiAutomation 的 ACTION_SET_TEXT 写入：限定淘宝固定搜索框，或带指定活动标识的网页搜索子树，并在手机端复核焦点、可编辑状态和非密码字段；随后读取核对文字才提交。无需安装 APK、常驻服务或 Android SDK；未修改系统无障碍开关。仅在当前 Xiaomi / Android 16 上验证过，其他系统可能不兼容。

重新构建需要 JDK 和网络访问 Google Maven：

```powershell
powershell -ExecutionPolicy Bypass -File tools/build-reader.ps1
```

构建脚本使用固定版本 R8/D8 `9.5.26`，首次下载到被 Git 忽略的工具目录。日常运行无需下载。

`artifacts/run-*` 包含本机页面截图、控件树、带本地时区的 `events.jsonl` 和完成结果 `results.json`，可能包含购物信息。它们不上传、不提交 Git；ADB 二进制、本机配置和构建缓存同样被 Git 忽略。

## 寻宝中国：观看直播集步数

手机进入“寻宝中国 → 赚步数 → 做任务 集步数”，窗口选择“寻宝中国 · 直播”后扫描并开始。也支持从已经打开的寻宝活动主页定位“赚步数”进入任务列表。

- 支持“逛一逛精选直播间”及各主播的“逛…直播间”任务；进入后读取真实倒计时，等组件显示“完成任务 / 获得奖励”或“恭喜完成任务”再返回。
- 直播观看预算为倒计时的1.2倍并向上取整，最低7秒：5秒任务给7秒，15秒给18秒，30秒给36秒。识别到完成立即返回。进入页面、ADB读取、返回与核验另计；当前手机最新完整任务实测16.47秒，7秒并非整条流程耗时。直播任务间隔为0.5秒，与赛车模式独立。
- 完成核验同时要求：该任务次数恰好增加1，且活动剩余步数按该行奖励增加。不凭停留时长、弹窗文字或红包金额判定成功。
- 末次完成后任务行被替换时，要求本次倒计时确实转为完成、步数精确增加，且仅原行在原位置被新任务替换、其他行内容及位置一致；条件不足时仍扫描完整列表核验原任务消失。
- 已适配本次实测的“天降红包”：同时核对弹窗文案与关闭图标，只点击弹窗自身的关闭按钮，每条任务最多3次；不点“马上去用”。关闭及暂停恢复后重新核对原直播间身份。
- 不点击直播间商品、购物车、领取、预约、关注、分享或评论。返回流程核对当前房间，最多按3次返回；任务列表上不会继续返回。保留成功与失败截图及逐帧XML记录。
- 自动模式持续发现剩余直播次数；邀请好友、游戏、农场、短视频和跨应用任务跳过。城市前进、星光兑换及红包领取由用户手动处理。
- 验证、系统权限弹窗、其他应用前台、未知直播页面、组件身份变化或次数／步数无法核验时停止并保存记录，不自动重做。

```powershell
python -m taojinbi --activity treasure
python -m taojinbi --activity treasure --scan
python -m taojinbi --activity treasure --all-browse --limit 0
python -m taojinbi --activity treasure --task 逛一逛李佳琦直播间 --limit 1
```

`--activity coins` 为淘金币赛车模式；省略活动参数时命令行任务操作默认使用赛车，窗口默认恢复上次活动。该扩展开发于 `feat/treasure-china-live`，验收后再合并发布。
