# 淘金币 ADB 浏览助手

Windows 本地工具，Python 3.14 + Tkinter，无第三方 Python 依赖。手机通过 USB 连接电脑，手动打开淘金币的“做任务赚能量”列表后启动。

## 使用

1. 双击 `start.cmd`。如果已经开着开发过程中的测试窗口，先关闭旧窗口再打开。
2. 点击“检查连接”，确认设备，然后点击“扫描任务”。
3. 默认勾选“自动处理全部可执行任务（站内浏览 + 跳转其他 APP）”，设置本次上限，点击“开始执行”。上限 `0` 表示持续发现并处理入口，直到耗尽或遇到异常。取消自动模式后，可以按列表勾选指定入口。
4. 可以暂停、继续或停止。停止后不再发送新操作；手机已经接收的手势可能完成。
5. “打开本地记录”可查看这次会话的日志、XML 和截图。
6. “完成提醒”可以分别关闭“响铃”和“置顶提示”，两个开关都会记住；程序不会发出无法关闭的提醒。

保持手机亮屏、淘宝处于前台，并避免同时手动操作。无需再给每个任务演示流程。

本机已放置 ADB 和所需 DLL 到 `tools/platform-tools/`。换电脑时，从 [Android 官方 Platform Tools](https://developer.android.com/tools/releases/platform-tools) 取得工具，并在窗口选择 `adb.exe`。小米设备需启用“USB 调试（安全设置）”，首次开启后重启手机。

## 当前支持范围

- **沉浸浏览**：等待页面任务组件结束，包含“好物沉浸看”等会轮换的名称。
- **商品列表浏览**：进入一张完整可见的商品卡片，浏览后返回，确认顶栏已得奖励；包含“好物随心逛”、`看看#…` 等入口。
- **签到与拍立淘浏览**：识别页面浏览组件并等待。拍立淘仅处理已有结果页，不拍照或上传图片；签到不操作提现、红包使用等按钮。
- **两种搜索浏览**：普通淘宝搜索页输入商品词后等待结果页任务浮标；“搜索有福利”页输入后进入结果中的商品阅读。默认商品词为“鼠标”，命令行可用 `--query` 修改。
- **攻略页**：已有条件识别与阅读处理，但今天该入口已完成，本轮没有取得未完成攻略页的真机验证。
- **跳转其他 APP**：识别 `点击去逛`、`逛一逛` 及支付宝、蚂蚁、闲鱼、天猫、微博、百度、快手等入口。点击“去完成”后等待外部应用出现在前台，停留 2 秒，再用 `am start` 把淘宝原有任务栈拉回前台，因此不需要数返回键次数；只有直接拉起失败时才退回按返回键，最多 3 次。外部应用内不点击任何按钮。
- **只在外部应用位于前台时才拉起淘宝**。已经在淘宝内时绝不调用 `am start`：那会新建一个 `Welcome` 活动并落回店铺首页，任务列表随之丢失。这类情况只按一次返回键，返回不到就停止并保存记录。
- **无奖励组件的站内活动页**：浏览任务可能落到车库页等站内活动页，页面里没有“浏览N秒”浮层。识别到稳定的站内未知页面后，按任务标注的时长停留，再返回并用总进度恰好增加1核验。
- 自动模式按浏览时长和页面任务组件发现任务，每次操作重新定位。完成后重新发现列表，支持名称与位置轮换；进入未识别的新页面时停止并保存记录。新的任务页面仍需单独适配，无法保证未来所有活动页直接可用。
- 同一帧出现同名但次数不同的行时（列表复用残留），先丢弃与其它行次数重复的那一行；仍无法区分时本轮不执行该行，但不会中断会话。
- 手动勾选跟随换名：某个槽位改名后仍保持勾选，不会因为标题变化而丢掉这一项。
- 答题、小游戏、邀请、积分兑换、下载安装、交易、关注、收藏、加购及授权操作均跳过。累计任务奖励的“立即领取”由用户手动处理。
- 验证、风险或网络提示、意外前台变化、未知页面、断连、超时、进度不明确都会停止输入。不会自动解决验证码或自动重做未确认成功的任务。
- 成功核验要求全局进度恰好增加1，并具备同组次数唯一变化，或本次页面从浏览中转为已完成的证据。单项次数存在歧义时明确记录“单项次数未归因”，不会借用其他行的次数。奖励数字精确匹配，商品标题中的完成文字不会作为任务组件证据。
- 跳转任务在外部应用内没有可读证据，只以返回淘宝后总进度恰好增加1确认，且必须观测到外部应用确实到过前台。没有增加时记录为未完成并在本轮跳过，不重试，不中断会话。

等待依据页面加载和任务要求；任务间采用5—10秒阅读间隔，避免连续快速点击。此工具无法保证不被平台识别。无障碍权限检测处理未实现。

## 命令行和离线测试

```powershell
python -m taojinbi --scan
python -m taojinbi --all-browse --limit 0
python -m taojinbi --all-browse --query 鼠标 --limit 1
python -m taojinbi --task 好物沉浸看 --limit 1
python -m taojinbi --task 好物沉浸看 --limit 0
python -m unittest discover -v
```

多台设备连接时使用 `--serial` 指定设备。命令行默认上限1次；窗口默认0。相同设备在本工具中只允许一个扫描或运行会话。

## 页面读取器与本地数据

`tools/ui-dump.jar` 是由本项目 Java 源码构建的约5KB页面读取器，经 ADB 临时放入 `/data/local/tmp/` 执行。它复用 Android 自带 UiAutomationShellWrapper 连接生命周期，直接读取控件树，避开系统 `uiautomator dump` 在动画页等待静止失败的问题。搜索文字通过 UiAutomation 的 ACTION_SET_TEXT 写入：限定淘宝固定搜索框，或带指定活动标识的网页搜索子树，并在手机端复核焦点、可编辑状态和非密码字段；随后读取核对文字才提交。无需安装 APK、常驻服务或 Android SDK；未修改系统无障碍开关。仅在当前 Xiaomi / Android 16 上验证过，其他系统可能不兼容。

重新构建需要 JDK 和网络访问 Google Maven：

```powershell
powershell -ExecutionPolicy Bypass -File tools/build-reader.ps1
```

构建脚本使用固定版本 R8/D8 `9.5.26`，首次下载到被 Git 忽略的工具目录。日常运行无需下载。

`artifacts/run-*` 包含本机页面截图、控件树、带本地时区的 `events.jsonl` 和完成结果 `results.json`，可能包含购物信息。它们不上传、不提交 Git；ADB 二进制、本机配置和构建缓存同样被 Git 忽略。
